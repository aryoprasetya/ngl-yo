Informasi kuis

Mode CAT memilih soal berdasarkan bobot poin yang ditetapkan per soal; CAT psikometrik penuh memerlukan bank soal terkalibrasi.
Dipakai jika timer per soal diaktifkan.
Peserta harus memasukkan kode ini sebelum memulai.
Pengaturan tampilan nilai dan pembahasan harus diberlakukan juga di sisi server. Menyembunyikan nilai pada HTML saja tidak cukup untuk menjaga kunci jawaban.

Bank soal

Pilihan ganda minimal dua opsi terisi; opsi C, D, dan E boleh dikosongkan. Atur poin tiap soal. Uraian disimpan dan memerlukan pemeriksaan manual oleh pengajar.

Koneksi API

Pengaturan koneksi Google Spreadsheet melalui Apps Script.

Google Apps Script Web App

Gunakan URL deployment Web App yang berakhiran /exec.
Jika server tidak menggunakan kunci admin, biarkan kosong. Hindari menyimpan rahasia penting pada halaman publik.

Langkah pemasangan

  1. Buat Google Spreadsheet sebagai database.
  2. Buka Ekstensi → Apps Script, lalu pasang kode server.
  3. Jalankan fungsi inisialisasi spreadsheet sesuai nama yang ada di kode server.
  4. Deploy sebagai Web App dan salin URL deployment.
  5. Simpan URL tersebut pada halaman ini dan halaman peserta.
Halaman admin statis tidak memiliki autentikasi yang kuat dengan sendirinya. Validasi akses admin, kunci jawaban, durasi, publikasi, dan pengumpulan nilai harus diperiksa oleh Apps Script di server.
